# 问题一

## 目录

- `src/problem1.py`：推荐运行入口，负责路径适配和输出目录管理。
- `src/problem1_analysis.py`：完整建模分析实现。
- `notebooks/problem1.ipynb`：Notebook 入口。
- `data/`：山西各年份一分一段输入数据。
- `outputs/`：运行生成的图表。

## 运行

从仓库根目录执行：

```bash
python "源程序代码/问题一/src/problem1.py"
```

主要分析内容包括新旧高考成绩分布、描述统计、高分段比例、Wasserstein/KS 距离以及反事实分布预测。
