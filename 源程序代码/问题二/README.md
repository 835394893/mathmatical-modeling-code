# 问题二

## 目录

- `src/problem2.py`：推荐运行入口，负责路径适配和输出目录管理。
- `src/problem2_analysis.py`：完整建模分析实现。
- `notebooks/problem2.ipynb`：Notebook 入口。
- `data/`：山西、河北、浙江及竞争环境评价输入数据。
- `outputs/`：换分表、TOPSIS 输入矩阵与评价结果等。

## 运行

从仓库根目录执行：

```bash
python "源程序代码/问题二/src/problem2.py"
```

主要分析内容包括跨省成绩分布比较、百分位保持换分模型，以及熵权法 + TOPSIS 高考竞争难度评价。
